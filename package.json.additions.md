Estos son los paquetes NPM que se agregan sobre los que instala `breeze:install react`:

npm install @inertiajs/react react react-dom
npm install -D @vitejs/plugin-react tailwindcss postcss autoprefixer

(Breeze con el flag react ya deja esto instalado; esta lista es solo referencia si armas
el front a mano sin usar el instalador de Breeze.)
